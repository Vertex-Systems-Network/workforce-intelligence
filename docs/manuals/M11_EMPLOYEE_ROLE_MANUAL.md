# WorkIntel Employee Role Manual

The employee path focuses on Tasks, Schedule, Attendance, Timesheets, Requests, Collaboration and personal Pay records when available. Start Here only recommends destinations the current member can actually access. Use Account to understand effective access when a page or action is intentionally unavailable.

Checklist completion is personal onboarding state; it never marks business work complete. Task status, attendance, timesheets, approvals and pay records retain their own authoritative workflows.
