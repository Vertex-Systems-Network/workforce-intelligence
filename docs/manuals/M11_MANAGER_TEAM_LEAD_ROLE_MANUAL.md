# WorkIntel Manager / Team Lead Role Manual

The manager path prioritizes Projects, Tasks, Approvals, Attendance and Collaboration. Start with delivery and exceptions rather than administrative configuration. Use project context before creating disconnected tasks or time records, clear approvals that block downstream workflows, and resolve attendance exceptions while team context is current.

Help recommendations are filtered by effective access. If a destination is not present, do not assume the product is broken: module enablement, permissions and data scope determine what a manager can actually see.
