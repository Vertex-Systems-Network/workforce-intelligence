# WorkIntel Owner / Administrator Role Manual

Use **Home → Start Here** to establish workspace identity, enabled modules, roles/scopes, people and reporting. The Owner/Admin path is configuration-first: verify workspace settings, then access boundaries, then operational modules. Effective permissions, explicit denies, data scopes, plan entitlements and enabled modules remain authoritative even when a role label suggests broad responsibility.

The Help Center is available from the shell on every page. Use **This page** for task-level first steps, **Start Here** for your personal checklist and **Role handbook** for accessible work areas. Changes under Settings, Roles & Access, Modules and Enterprise Governance can affect other users, so distinguish workspace-wide configuration from personal UI preferences.
