WorkIntel — Chat V2.1 Professional Collaboration Stabilization
Date: 2026-08-13
Base: WorkIntel P11 Strict Clean Release

IMPLEMENTED
- Current signed-in workspace member excluded from New Conversation options server-side and client-side.
- Inactive/suspended/archived workspace memberships excluded from creation options.
- Workspace members backed by suspended/inactive global User records excluded from creation options.
- Explicit self-DM API request rejected with HTTP 422 and code SELF_CONVERSATION_NOT_ALLOWED.
- Canonical two-person direct-message pairs reuse the existing conversation instead of creating duplicates.
- Previously archived canonical DM is reopened instead of creating a second pair.
- Auth workspace mapping now preserves member_id as memberId for reliable self identity in UI.
- Conversation list response exposes viewer_member_id as a second server-trusted identity source.
- Presence query filters inactive members and remains restricted to members sharing conversations with the viewer.
- Conversation online indicator excludes the signed-in member so the user's own presence cannot make a peer appear online.
- Mention quick-picks exclude the signed-in member.
- Desktop chat stabilized as three panes: conversations / active chat / details.
- Tablet conversation details use an overlay drawer.
- Mobile chat uses one panel at a time instead of stacking list + chat + details vertically.
- Message polling no longer unconditionally forces the reader to the bottom.
- Added unread divider and Jump to latest behavior.
- Read cursor advances when the viewer reaches/latest message rather than on every background poll.
- Typing presence is debounced instead of making a request on every keystroke.
- Pinned-message and navigation styling use RTL-safe logical properties for Urdu/Arabic.
- Existing Chat module-off, private attachment, mentions, reactions, pins and project/task scope behavior retained.
- Strict release verification scripts now include Chat V2.1 smoke and targeted PHPUnit gates.
